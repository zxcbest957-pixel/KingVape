# 👑 KingVape (Privacy & Security Edition)

Прошитая и безопасная версия клиента Vape V4 / CatV6.

### 🛡️ Улучшения безопасности:
- **Удалены удалённые бэкдор-команды**: вырезаны `;uninject`, `;kick`, `;kill`, `;crash`, `;toggle`, `;reveal`.
- **Удалён внешний вайтлист**: вырезана загрузка `ah2r/whitelist`, никто не имеет админских прав над вашим клиентом.
- **Безопасный StaffDetector**: нейтрализованы функции принудительной выгрузки `vape:Uninject()` и сброса биндов `AutoConfig`.
- **Защита локальных конфигов**: вырезан авто-вайп папки `catsix/`.
- **Защита от подмены `Uninject`**: заблокированы попытки подменить вашу кнопку выключения чита.
